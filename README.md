# Focus_tool_

🔹 What This Tool Does
Helps users focus and organize tasks
Uses Pomodoro technique (25 minutes)
Saves tasks automatically
Works offline

🔹 Technologies Used
HTML – structure
CSS – styling
JavaScript – logic + storage

🔹 Key Concepts Demonstrated
DOM manipulation
localStorage
setInterval (timers)
Clean UI logic separation

🔹 How to Run
Create the three files
Open index.html in any browser
No internet required
